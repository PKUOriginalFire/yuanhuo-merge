# 游玩数据的公开口径

## 为什么敢公开

原始数据里**从来没有采集过**昵称以外的身份信息。玩家身份是一个随机 UUID，
存在浏览器 localStorage 里，清掉缓存就换一个；服务端只额外存了一个
加盐哈希后的 IP（用于同一网络多账号检测），盐值不公开、也不导出。

公开版在这个基础上又做了一层：

| 原始 | 公开版 |
|---|---|
| clientId（随机 UUID） | `p0001`…（按首次提交时间排序） |
| 昵称 | 不导出 |
| ip_hash（加盐） | 不导出 |
| trace（每次投放的时间与横坐标） | 不导出 |
| 提交时间（毫秒时间戳） | UTC ISO 8601 |

## 为什么昵称要拿掉

昵称是玩家自己起的，属于个人标识。虽然它们本来就显示在公开排行榜上，
但把昵称和「哪一局被判作弊」关联起来公开展示，性质就不一样了——
那等于给具体的人贴标签。所以公开数据集只保留「这局是否被判可疑」这个布尔值，
以及在正文里用「玩家 A/B/C」这种编号叙述个案。

## 保留了什么

分数、等级、合成次数、落球数、时长、模式、是否被判可疑、提交时间。
这些足够复现本仓库里所有关于分布、标定和判据的分析：

- 分数分布 → `tools/measure-score-curve.mjs`
- 落球/时长分布 → `tools/export-analytics.mjs`
- 台账不变量 → `tools/validate-ledger.mjs`
- 判据误伤面 → `tools/audit-clean-runs.mjs`
